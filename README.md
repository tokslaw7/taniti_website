# Taniti Travel Website

> **Coursework notice:** The government of Taniti, a small island whose economy depends heavily on tourism, wants a new tourism website to attract more visitors and improve tourists' experience. Research from a tourist survey and information about the island have been provided to guide the project.

The current website has several problems:

An outdated design
Confusing navigation
All information crowded onto a single page
No booking information or links to activities and attractions
Poor compatibility with mobile devices

You have been hired to redesign the website within one month. The new site should be modern, user-friendly, mobile-responsive, and organized in a way that helps prospective tourists easily find information, explore attractions, and make travel plans, ultimately increasing tourism to Taniti.

## Overview

A static travel-information website for visitors to Taniti. It includes pages for activities, places to stay, food and dining, transportation, trip planning, bookings, and destination information.

## Built with

- HTML
- CSS
- JavaScript

## Run locally

From the project directory, start a local web server:

```sh
python3 -m http.server 8000
```

Then open [http://localhost:8000](http://localhost:8000) in a browser.

## Project files

- `index.html` — homepage and primary navigation
- `styles.css` — shared page styles and responsive layouts
- `script.js` — client-side form behavior
